# Security Policy

## Supported versions

The latest release on npm (`@excellent-so/screen-map`) is the only supported version.
Fixes are not backported to older releases.

## Reporting a vulnerability

Please report vulnerabilities privately to **matt@excellent.so** rather than opening a
public issue. Include a description of the issue and reproduction steps if possible.
You should receive a response within a few business days.

There is no bug bounty program.
